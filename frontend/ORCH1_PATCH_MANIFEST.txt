AutoFlow ORCH-1 Server Orchestrator Foundation

Scope:
- Opt-in server-side execution lane only.
- Existing React Execute Workflow path is untouched.
- Supports only: Start -> one non-multipart API plugin -> End.
- Requires PostgreSQL workspace + execution persistence and execution writes.
- Persists an initial run and every completed/failed node through existing executionRepository.js.
- Uses PostgreSQL plugin_endpoint_mapping first; falls back to the saved action API route.
- Engine calls are pinned to configured ENGINE_URL to avoid arbitrary workflow-controlled hosts.
- Cross-node bindings, loops, branches, retries, multipart/files and debugger behavior are intentionally rejected in ORCH-1.
